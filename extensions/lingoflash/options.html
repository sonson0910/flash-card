LINGOFLASH EXTENSION

Cài đặt

Mặc định trỏ tới bản production. Chỉ HTTPS được chấp nhận, ngoại trừ localhost khi phát triển.

Phím tắt

Phím đang dùng: Ctrl/⌘ + Shift + L

Chrome: mở Extensions → Keyboard shortcuts. Trên Safari, quản lý extension tại Safari → Settings → Extensions.

Quyền riêng tư

Extension không lưu token Firebase hay API key. Đoạn text chỉ được chuyển sang tab LingoFlash; app đã đăng nhập chịu trách nhiệm dịch và lưu card.
